# Failure Experiment

This task is about **persist response**. Do not stop after a successful request.

1. Start the complete stack.
2. Make a successful request.
3. Identify the dependency that demonstrates this concept.
4. Stop or make that dependency unavailable.
5. Repeat the same request.
6. Observe the HTTP response and logs.
7. Restore the dependency.
8. Explain the recovery path.
